# Contributing to Simple Interest Calculator

Thank you for taking the time to contribute! Contributions are what make the open source community such an amazing place to learn, inspire, and create.

## How to Contribute

### Reporting Bugs
If you find a bug or error in documentation:
1. Check the existing Issues to make sure it has not already been reported.
2. Open a new issue with a clear title and description explaining the problem and how to reproduce it.

### Suggesting Enhancements
Feature requests and improvements are welcome:
1. Open an issue describing the proposed feature or improvement.
2. Explain why this enhancement would be useful to the project.

### Pull Request Process
1. **Fork** the repository to your own GitHub account.
2. **Clone** your fork locally:
   ```bash
   git clone [https://github.com/](https://github.com/)<your-username>/github-final-project.git
